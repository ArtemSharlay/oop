## 🎮 Описание игры

"Быки и коровы" - это логическая игра, в которой компьютер загадывает число из 3-6 цифр, а игрок пытается его отгадать. После каждой попытки компьютер сообщает количество "быков" (цифр на своих местах) и "коров" (цифр, присутствующих в числе, но не на своих местах).

**Особенности реализации:**
- Случайная генерация секретного числа
- Ограничение по времени на ввод 
- Логирование всех действий в файл
